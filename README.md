# خدای سکه‌ها 🪙⚡

یک بازی خدایی (god game) با آدمک‌های سرسکه‌ای. تو خدایی و آن‌ها زندگی می‌کنند: میوه می‌چینند، در معدن سکه درمی‌آورند، خانه می‌سازند، با هم گپ می‌زنند، عاشق می‌شوند، ازدواج می‌کنند، بچه‌دار می‌شوند، قبیله تشکیل می‌دهند، متحد می‌شوند و با هم می‌جنگند. تو هم می‌توانی برکتشان بدهی یا روزگارشان را سیاه کنی.

## اجرا

```bash
npm install
npm run dev
```

## دنیا

- سرزمینی با رودخانه و پل‌ها، دریاچه‌ها، تپه‌ها، کوه‌های برفی و یک **تپه‌ی مقدس** در میانه.
- **فصل‌ها** (بهار، تابستان، پاییز، زمستان) رنگ زمین و درخت‌ها را عوض می‌کنند. در زمستان درخت‌ها میوه نمی‌دهند و بی‌خانمان‌ها سرما می‌خورند.
- **آب‌وهوا**: صاف، ابری، باران، طوفان با صاعقه، برف و مه.
- **شب و روز** با نور واقعی: پنجره‌ها، آتش‌ها، مشعل سربازها و شهر مقدس در تاریکی می‌درخشند.
- پرنده‌ها، پروانه‌ها، کرم‌های شب‌تاب، ماهی‌هایی که از آب می‌پرند، برگ‌هایی که می‌ریزند و سایه‌ی ابرها.
- روستاها بزرگ می‌شوند: کلبه‌ی چوبی، خانه‌ی سنگی با دودکش، معبد، قلعه و جاده‌هایی که بین خانه‌ها کشیده می‌شوند.

## آدم‌ها

- هر کدام شکل سر (سکه، چهارگوش، سه‌گوش، شش‌گوش، ستاره)، رنگ و شخصیت خودشان را دارند: مهربانی، پرخاشگری، طمع، اجتماعی بودن، ایمان به خدا، شجاعت، سخت‌کوشی.
- نیاز دارند (غذا، خواب، هم‌صحبت، سلامتی)، میوه می‌چینند، ماهی می‌گیرند، پول جمع می‌کنند، خانه می‌سازند، پیر می‌شوند و می‌میرند.
- رابطه‌هایشان را به یاد دارند: دوستی، کینه، عشق، سوگ. بچه‌ها شخصیت و دینی ترکیبی از پدر و مادرشان دارند.
- دوستان با هم قبیله می‌سازند؛ قبیله‌ها رهبر دارند، سر مرز دعوا می‌کنند، اعلان جنگ می‌دهند، صلح می‌کنند و در برابر دشمن مشترک متحد می‌شوند.

## آیین‌ها و جنگ‌های مقدس

- دنیا با دو قوم شروع می‌شود: **آیین خورشید ☀️** در غرب رود و **آیین ماه 🌙** در شرق. شهر مقدس در میانه بی‌صاحب است.
- هر آیین پیامبری (با هاله) دارد. مؤمنان تبلیغ می‌کنند و دیگران را به دینشان درمی‌آورند، به زیارت شهر مقدس می‌روند، معبد می‌سازند و در آن دعا می‌کنند.
- **کینه‌ی دینی** جمع می‌شود: شهر مقدس دست دیگری است، هم‌کیشان کشته شده‌اند، معبدی سوخته، یا بلایی آمده که تقصیرش را گردن «کافرها» می‌اندازند.
- وقتی کینه سر ریز کند، **جنگ مقدس** اعلام می‌شود (جنگ مقدس اول، دوم، …): سپاهی با فرمانده، پرچم‌دار، شمشیرزن و کماندار زیر پرچم آیینشان جمع می‌شوند، از روی پل‌ها از رود رد می‌شوند و شهر مقدس (یا شهر دشمن) را محاصره می‌کنند. طرف مقابل سپاه دفاعی جمع می‌کند.
- **انشعاب**: وقتی یک آیین خیلی بزرگ شود، یک مؤمن ناراضی جدا می‌شود و آیین تازه‌ای می‌سازد (ستاره ⭐، آتش 🔥، درخت 🌳، آب 💧…).
- وقتی سرزمین خالی شود، مهاجران از راه می‌رسند.

## قدرت‌های خدا

✋ برداشتن و پرت کردن آدم‌ها · ⚡ صاعقه · 🔥 آتش · ☄️ شهاب‌سنگ · 🌋 زلزله · 🦠 طاعون · 💰 باران طلا · ✨ برکت و شفا · 🕊️ معجزه (بی‌دین‌ها به آیینِ آن‌جا می‌گروند) · 😈 فتنه (کینه میان قوم‌ها و آیین‌ها) · 🌧️ باران · 🌳 کاشتن درخت · 🧍 آفریدن آدم تازه

روی هر آدم بزنید تا پرونده‌اش را ببینید (شخصیت، دین، روابط، خاطرات) و از آسمان با او حرف بزنید. اگر با یک آدمِ مؤمن حرف بزنید، ممکن است ادعای پیامبری کند یا آیین تازه‌ای بسازد.

## هوش آدم‌ها (رایگان، بدون اینترنت)

- **🧠 مغز شبکه‌ی عصبی:** هر آدم یک شبکه‌ی عصبی کوچک دارد (۱۴ حس ← ۸ نورون ← ۱۲ خواسته). حالش را می‌خواند (گرسنگی، خستگی، خطر، شب، زمستان، خانه، همسر…) و تصمیم‌هایش را کم و زیاد می‌کند.
  - **یادگیری:** کاری که شادش کرده را بعداً بیشتر می‌خواهد.
  - **تکامل:** بچه‌ها ترکیبی از مغز پدر و مادر را با کمی جهش به ارث می‌برند. آن‌هایی که زنده می‌مانند و بچه‌دار می‌شوند مغزشان را منتقل می‌کنند؛ پس جمعیت نسل به نسل تکامل پیدا می‌کند. در پرونده‌ی هر آدم مغزش زنده نمایش داده می‌شود.
- **🐜 الگوریتم مورچه‌ها (Ant Colony):** آدم‌ها فقط درخت‌های نزدیک را می‌بینند. هر کس غذا پیدا کند ردّ غذا می‌گذارد و گرسنه‌ها آن را دنبال می‌کنند. جای دعوا و مرگ بوی خطر می‌گیرد و از آن دوری می‌کنند. قدم‌ها روی زمین کم‌کم راه می‌سازند. با دکمه‌ی «🐜 ردپاها» می‌توانید این ردها را ببینید.
- **🐦 الگوریتم پرندگان (Boids):** پرنده‌ها، سپاه‌های در حال حرکت و جمعیتِ فراری مثل یک گله با هم حرکت می‌کنند.

## ذهن‌های هوشمند (Claude، اختیاری)

بدون هوش مصنوعی هم دنیا زنده است. اگر در بخش «هوش» یک کلید API از Anthropic بگذارید، هر چند ثانیه ذهن یکی از آدم‌ها با Claude فکر می‌کند: شخصیت، خاطرات، اطرافیان و اخبار دنیا را می‌خواند و تصمیم می‌گیرد چه فکر کند، چه بگوید و چه کند (گپ، خواستگاری، دعوا، دزدی، هدیه، دعا، تبلیغ دین، زیارت، ساختن قبیله، اعلان جنگ، صلح، و برای پیامبرها و رهبرها: اعلان جنگ مقدس). وقتی با کسی حرف بزنید، جواب واقعی می‌دهد و آن را به یاد می‌سپارد.

- هر فکر یک درخواست API است و هزینه دارد؛ فاصله‌ی فکر کردن را در تنظیمات زیاد کنید تا ارزان‌تر شود.
- کلید فقط در مرورگر خودتان ذخیره می‌شود. نسخه‌ای را که کلیدتان در آن است جای عمومی منتشر نکنید.

# بنر Coin Crowd — بنر آدمک‌های سکه‌ای

کد بنر صفحه‌ی اصلی (جمعیت آدمک‌های سر‌سکه‌ای) جدا شده تا در یک پروژه‌ی جدید React استفاده شود.
هیچ وابستگی‌ای جز `react` ندارد.

## فایل‌ها

| فایل | کار |
| --- | --- |
| `Figure.jsx` | خود آدمک به صورت SVG (`figureSvg`) و کامپوننت `<Figure />` |
| `CoinCrowd.jsx` | بنر: جمعیت روی canvas که دنبال موس/انگشت می‌آیند، عصبانی می‌شوند، گوجه و تخم‌مرغ پرت می‌کنند |
| `coin-crowd.css` | استایل بنر و آدمک (خودش داخل `CoinCrowd.jsx` import می‌شود؛ برای `Figure` تنها، دستی import کنید) |
| `Example.jsx` | نمونه‌ی استفاده |

## نصب

۱. اجرای نمونه: `npm install` و بعد `npm run dev`. برای استفاده در پروژه‌ی دیگر، پوشه‌ی `src/crowd/` را کپی کنید.
۲. (اختیاری) فونت‌ها برای متن فارسی:

```bash
npm i @fontsource-variable/estedad @fontsource-variable/vazirmatn
```

```js
import "@fontsource-variable/estedad";
import "@fontsource-variable/vazirmatn";
```

۳. استفاده:

```jsx
import CoinCrowd from "./crowd/CoinCrowd.jsx";

<CoinCrowd title="عنوان" text="زیرعنوان" count={12} />
```

## پراپ‌های `CoinCrowd`

| پراپ | پیش‌فرض | توضیح |
| --- | --- | --- |
| `title`, `text` | — | عنوان و زیرعنوان روی بنر |
| `count` | `12` | تعداد آدمک‌ها |
| `done` | `0` | چند نفر تیک سبز بالای سرشان دارند |
| `present` | `count` | چند صندلی پر است؛ بقیه کم‌رنگ |
| `cast` | همه `plain` | نوع هر آدمک به ترتیب: `"plain"`، `"me"` (سکه‌ی طلایی با برچسب «شما»)، `"logo"` (سکه‌ی آبی با لوگو) |
| `meDone` | `false` | «شما» هم تیک بخورد |
| `angry` | `false` | بنر قرمز و آدمک‌ها عصبانی |
| `pelting` | `false` | (با `angry`) به «شما» گوجه و تخم‌مرغ پرت می‌کنند |
| `action` | — | یک دکمه زیر متن (کلاس `crowd-action` بدهید) |
| `hintMouse`, `hintTouch` | متن فارسی | راهنمای بار اول |
| `className` | — | مثلاً `"crowd-full"` برای بنر تمام‌صفحه روی دسکتاپ |

## پراپ‌های `Figure`

`size`، `pose` (`"stand"` / `"a"` / `"b"`)، `face` (رنگ سکه)، `label`، `labelColor`، `check`، `empty`، `logo`، `angry`، `me`، `worried`، `title`.

## شخصی‌سازی سریع

- رنگ پس‌زمینه: `.crowd { background }` در `coin-crowd.css`.
- رنگ خط: `INK` در `Figure.jsx`.
- لوگوی روی سکه: متغیر `mark` در `figureSvg` (الان شورون سفید و سکه‌ی طلایی دیجی‌پی است — برای برند خودتان عوضش کنید).
- کلمه‌های برخورد («شلپ!» / «ترق!») و برچسب «شما»: داخل `CoinCrowd.jsx`.
